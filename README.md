Solmar Bay is an original open-world crime game in the browser: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police under a 5-star wanted system, and play five story missions with taxi fares, stunt jumps and hidden cash on the side.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move and drive, E to steal or enter a car, mouse aim and click to shoot, M for the next story mission, T for a taxi fare, P to pause. No network, no build step — the game is plain static files under `game/`.
